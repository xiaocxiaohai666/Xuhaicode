# 预约系统版本2

> 基于 C++ + epoll + pthread + MySQL 的多线程并发预约系统
> 包含连接池、线程池、epoll I/O 多路复用、JSON 协议、SQL 事务

---

## 一、项目概述

### 1.1 项目定位
一个支持多客户端同时在线的票务预约系统，客户端通过 TCP 长连接与服务端交互，服务端使用 epoll 监听 I/O 事件，并通过线程池把任务交给 worker 线程处理，worker 线程通过连接池借用 MySQL 连接执行 SQL。

### 1.2 核心特性

| 特性 | 实现方式 |
|------|----------|
| 并发模型 | epoll + pthread 线程池 |
| 数据库复用 | Connect_Pool 连接池（5 个连接复用） |
| 协议格式 | JSON（基于 jsoncpp） |
| 事务支持 | 预约/取消操作使用 MySQL 事务 |
| 容错 | 连接池满时返回 "MYSQL CLIENT BUSSY"，客户端提示重试 |

### 1.3 业务功能
- 用户注册（手机号 + 用户名 + 密码）
- 用户登录
- 查看可预约票列表
- 预约票（带事务，防止超卖）
- 查看我的预约
- 取消预约（带事务，保持 count 一致）

## 三、改进建议

### 3.1 性能改进

#### 3.1.1 连接池加条件变量（当前最大短板）
**现状**：[Connect_Mysql_Server](service.cpp#L474) 借不到连接直接 `return false`，构造失败 → 客户端收到 BUSSY。
**问题**：并发请求超过 5 个时，第 6 个直接被拒，用户体验差。
**改进**：在 `Connect_Pool` 加 `pthread_cond_t`，借不到时 `pthread_cond_wait`，等他人归还后唤醒。
```cpp
// 借连接
while (C_P_array[i].status == false) pthread_cond_wait(&cond, &mutex);
// 归还时
pthread_cond_signal(&cond);
```

#### 3.1.2 worker 线程绑定固定连接（彻底消除锁）
**现状**：5 个 worker 共享 5 个连接，借/还都要加锁。
**改进**：worker 启动时绑死一个连接（线程局部存储 `__thread` 或 `pthread_key`），完全无锁。

#### 3.1.3 send/recv 改非阻塞 + 边沿触发
**现状**：epoll 用 Level Triggered + EPOLLONESHOT，每次要重新 MOD。
**改进**：改 Edge Triggered + 非阻塞 fd，循环 recv 到 EAGAIN，减少 epoll_ctl 调用。

#### 3.1.4 SQL 预处理语句
**现状**：每次 `mysql_query` 拼字符串，服务端每次都要 parse SQL。
**改进**：用 `mysql_stmt_prepare` + `mysql_stmt_bind_param`，复用执行计划。

---

### 3.2 安全改进

#### 3.2.1 SQL 注入（必改）
**现状**：[Db_User_Register](service.cpp#L506)、[Db_User_Login](service.cpp#L520) 等直接拼字符串：
```cpp
string sql = "select Name,Passwd from user_info where Tel='" + tel + "'";
```
**风险**：用户 tel 输入 `' OR '1'='1` 直接绕过密码校验。
**改进**：用 `mysql_real_escape_string` 转义，或改 prepared statement。

#### 3.2.2 密码明文存储
**现状**：[Db_User_Register](service.cpp#L506) `values(0,'tel','name','passwd',...)` 直接存明文。
**风险**：数据库被拖库后密码全暴露。
**改进**：用 `crypt()`/`SHA256`/`bcrypt` 存哈希，登录时比哈希。

#### 3.2.3 客户端不验证服务端身份
**现状**：客户端直接 `connect`，无法识别中间人。
**改进**：用 TLS（OpenSSL）加密通道。

---

### 3.3 健壮性改进

#### 3.3.1 signal 处理
**现状**：`Ctrl+C` 时 `epoll_wait` 会被 EINTR 中断，但 [L895-L900](service.cpp#L895) 直接 `exit(1)`，不释放资源。
**改进**：注册 `SIGINT/SIGTERM` handler，设 `Status = false`，让主循环优雅退出，析构 `Tcp_Service` → 析构 `Thread_Pool` → join 所有 worker。

#### 3.3.2 客户端断连感知
**现状**：客户端 `Ctrl+C` 退出，服务端 [Do_client](service.cpp#L174) 收到 `recv_num == 0` 走 `delete this`，OK。但如果客户端网络异常（没发 FIN），服务端不知道。
**改进**：用 TCP keepalive（`setsockopt SO_KEEPALIVE`）或应用层心跳。

#### 3.3.3 EPOLLONESHOT 处理一致
**现状**：listen socket 没用 EPOLLONESHOT，client socket 用了。
**风险**：多线程同时 accept 同一个 listen fd，可能竞争。
**改进**：listen fd 也用 EPOLLONESHOT，accept 后重新 MOD。

#### 3.3.4 配置文件硬编码路径
**现状**：[service.h#L22](service.h#L22) `#define Conf_path "/home/xiaoc/mycode/csproject2/service.conf"`，换机器就废。
**改进**：从 argv[1] 读，或读环境变量。

#### 3.3.5 mysql_real_connect 密码硬编码
**现状**：[Connect_Pool::Run](service.cpp#L787) `"root","111111"` 写死在代码里。
**改进**：从 `mysql.conf` 读用户名/密码，或用 MySQL 配置文件 `[client]` 段。

---

### 3.4 可维护性改进

#### 3.4.1 头文件依赖混乱
**现状**：[service.h](service.h) 把 `Service_Config`、`Socket`、`AccSocket`、`RecvSocket`、`Thread_Pool`、`Mysql_config`、`Mysql_Client`、`Mysql_cli`、`Connect_Pool`、`Tcp_Service` 10 个类型全堆在一个文件。
**改进**：拆分成 `socket.h`、`thread_pool.h`、`mysql_pool.h`、`mysql_client.h`、`tcp_service.h`、`service_config.h`，每个文件单一职责。

#### 3.4.2 全局变量
**现状**：[service.cpp#L15-L16](service.cpp#L15) `Mysql_config file;` 和 `Connect_Pool* g_pool;` 是全局变量。
**问题**：难追踪修改点，难单元测试。
**改进**：`g_pool` 改成 `Connect_Pool::GetInstance()` 单例；`file` 放到 `Tcp_Service` 里作成员。

#### 3.4.3 裸指针 + 手动 new/delete
**现状**：`Socket* task`、`Mysql_cli* C_P_array` 等全是裸指针，靠 `delete` 手动管理。
**风险**：异常路径漏 delete 会泄漏。
**改进**：用 `std::unique_ptr` / `std::shared_ptr`，析构自动释放。

#### 3.4.4 错误日志不分级
**现状**：所有错误都 `cout <<` 打到 stdout。
**改进**：引入简单日志库（如 spdlog），分 INFO/WARN/ERROR/FATAL，支持文件分卷。

#### 3.4.5 magic number
**现状**：[service.cpp#L787](service.cpp#L787) `"root","111111"`、[client.h#L18](client.h#L18) `PORTADRESS 8888`、`MAXLINE 256`、`d_size 1024` 等硬编码。
**改进**：全部移到配置文件或 const 常量。

---

### 3.5 功能扩展

#### 3.5.1 缺少客户端超时
客户端 [recv](client.cpp#L113) 是阻塞的，服务端挂了客户端会一直等。
**改进**：用 `setsockopt SO_RCVTIMEO` 设 5 秒超时，超时提示。

#### 3.5.2 缺少管理员后台
现在无法后台管理票务（增删改查票、查用户、统计）。
**改进**：加一个管理端协议 type=Admin_Login + type=Admin_Add_Ticket 等。

#### 3.5.3 缺少并发数统计
无法查看当前在线用户、池使用率。
**改进**：服务端加一个 stats 接口（可通过 SIGUSR1 信号 dump 状态到日志）。

```cpp
void Service_Config::ReadConfig(const char *config_path) {
  if (config_path == nullptr) {
    cout << "config_path is nullptr!" << endl;
    return;
  }

  FILE *fp = fopen(config_path, "r");
  if (fp == nullptr) {
    perror("fopen config file failed");
    cout << "fopen config file failed! errno=" << errno << endl;
    return;
  }

  char line[MAXLINE]{0};
  int num = 0;

  while (fgets(line, MAXLINE - 2, fp) != nullptr) {
    num++;
    if (line[0] == '#' || line[0] == '\n') {
      continue;
    }

    char *Before = strtok(line, "=");
    char *After = strtok(nullptr, "=");

    if (Before == nullptr || After == nullptr) {
      continue;
    }

    After[strlen(After) - 1] = '\0';

    if (strcmp("ip", Before) == 0) {
      IP = After; // 禁止共享内存，line是一次性使用，After会被覆盖
    } else if (strcmp("port", Before) == 0) {
      Port = atoi(After);
    } else if (strcmp("lismax", Before) == 0) {
      Lismax = atoi(After);
    } else if (strcmp("service_conf_path", Before) == 0) {
      config_path = After;
    } else {
      cout << "unknown config item: " << Before << " at line " << num << endl;
    }
    memset(line, 0, sizeof(line));
  }
  fclose(fp);
}

void AccSocket::Do_client() {
  struct sockaddr_in client_addr;
  socklen_t client_addr_len = sizeof(client_addr);
  memset(&client_addr, 0, sizeof(client_addr));

  // lis_fd对accept的影响，在默认情况下，lis_fd在队列为空时，会默认让accept在获取这个空队列时阻塞，线程会直接阻塞卡死在这
  // 所以我们要用非阻塞模式的accept，当队列为空时，accept会返回EAGAIN或EWOULDBLOCK，而不是阻塞线程
  int conn_fd = accept(fd, (struct sockaddr *)&client_addr, &client_addr_len);

  if (conn_fd < 0) {
    if (errno == EAGAIN || errno == EWOULDBLOCK) {
      // listen 队列空了,别的 worker 已经把连接取走了,正常退出
      delete this;
      return;
    }

    perror("accept failed");
    cout << "accept failed! errno=" << errno << endl;
    delete this;
    return;
  }

  cout << "client:" << conn_fd << " connect success!" << endl;
  cout << "Service accept client numb now: " << ++count << endl;
  cout << "-------------------------------------" << endl;

  struct epoll_event ev_client_accpet;
  ev_client_accpet.events = EPOLLIN | EPOLLONESHOT;
  auto *recvSock = new RecvSocket(conn_fd, epfd);
  ev_client_accpet.data.ptr = recvSock;

  if (epoll_ctl(epfd, EPOLL_CTL_ADD, conn_fd, &ev_client_accpet) == -1) {
    perror("epoll_ctl add client fd failed");
    cout << "epoll_client_ctl add false! errno=" << errno << endl;
    close(conn_fd);  // 关闭连接,不受监控的不要
    delete recvSock; // 删除对象
  }

  delete this;
}

void RecvSocket::Do_client() {
  char buff[MAXLINE]{0};
  ssize_t recv_num = recv(fd, buff, sizeof(buff) - 1, 0);

  bool tag = false;

  if (recv_num < 0) {
    perror("recv failed");
    cout << "[fd=" << fd << "] recv 出错 errno=" << errno << endl;
    tag = true;
  } else if (recv_num == 0) {
    cout << "[fd=" << fd << "] 客户端正常关闭连接" << endl;
    tag = true;
  } else {
    buff[recv_num] = '\0';
    cout << "[fd=" << fd << "] 收到 " << recv_num << " 字节" << endl;
    cout << "---------------------------------------------" << endl;

    Json::Value val;
    Json::Reader read;
    if (!read.parse(buff, val)) {
      cout << "[fd=" << fd << "] Json 解析失败! 收到内容: " << buff << endl;
      tag = true;
    } else {

      Mysql_Client sql(&file,fd);
      if (sql.IsConnected()) {
      int i = val["type"].asInt();
      if (i == Login) {
        string user_tel = val["user_tel"].asString();
        string passwd = val["passwd"].asString();
        string user_name = val["user_name"].asString();
        if (sql.Db_User_Login(user_tel, user_name, passwd)) {
          send_Ok();
        } else {
          send_false();
        }
      } else if (i == Register) {
        string tel = val["user_tel"].asString();
        string name = val["user_name"].asString();
        string passwd = val["passwd"].asString();
        if (sql.Db_User_Register(tel, name, passwd)) {
          send_Ok();
        } else {
          send_false();
        }

      } else if (i == CheckApoint) {
        Json::Value Reader;
        if (!sql.Db_Show_Ticket(Reader)) {
          send_false();
        } else
          send(fd, Reader.toStyledString().c_str(),
               strlen(Reader.toStyledString().c_str()), 0);
      } else if (i == Appointment) {
        string user_tel = val["user_tel"].asString();
        string ticket_id = val["ticket_id"].asString();
        if (!sql.Db_Yd_Ticket(user_tel, ticket_id)) {
          send_false();
        } else {
          send_Ok();
        }
      } else if (i == AppoinMessage) {
        string user_tel = val["user_tel"].asString();
        Json::Value res;
        if (!sql.Db_Show_My_Ticket(user_tel, res)) {
          send_false();
        } else {
          send(fd, res.toStyledString().c_str(),
               strlen(res.toStyledString().c_str()), 0);
        }
      } else if (i == CancelAppoin) {
        string user_tel = val["user_tel"].asString();
        string yd_id = val["yd_id"].asString();
        if (!sql.Db_Cancel_Ticket(user_tel, yd_id)) {
          send_false();
        } else {
          send_Ok();
        }
      } else {
        tag = true;
      }
      }
    }
  }


  if (tag) {
    epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
    delete this;
  } else {
    struct epoll_event ev;
    ev.events = EPOLLIN | EPOLLONESHOT;
    ev.data.ptr = this;
    epoll_ctl(epfd, EPOLL_CTL_MOD, fd, &ev);
  }
}

Thread_Pool::Thread_Pool() {
  if (!Init_Thread_pool()) {
  exit(1);
  }

  Create_Thread();
}

Thread_Pool::~Thread_Pool() {
  pthread_mutex_lock(&mutex);
  status = false;
  pthread_cond_broadcast(&cond); // 唤醒所有在 cond_wait 的线程
  pthread_mutex_unlock(&mutex);

  for (int i = 0; i < thread_num; i++) {
    pthread_join(Thread_array[i], NULL);
  }
  free(dequeue);
  pthread_mutex_destroy(&mutex);
  pthread_cond_destroy(&cond);
}

bool Thread_Pool::Init_Thread_pool() {

  dequeue = (task_t *)malloc(sizeof(task_t) * d_size);

  if (dequeue == nullptr) {
    cout << "dequeue malloc failure" << endl;
    return false;
  }

  dequeue_size = d_size;
  front = 0;
  rear = front;
  task_Num = 0;
  thread_Num = thread_num;

  pthread_cond_init(&cond, NULL);
  pthread_mutex_init(&mutex, NULL);

  status = true;
  cout << "ThreadPool init success!" << endl;
  cout << "---------------------------------------" << endl;

  return true;
}

void Thread_Pool::add_Task(Socket *csocket) {
  pthread_mutex_lock(&mutex);
  if (task_Num >= dequeue_size) {
    delete csocket;
    cout << "dequeue_size is full!add_Task false!" << endl;
    pthread_mutex_unlock(&mutex);
    return;
  }

  dequeue[rear].task = csocket;
  rear = (rear + 1) % dequeue_size;
  task_Num++;

  pthread_cond_signal(&cond);
  pthread_mutex_unlock(&mutex);
}

void *General_Thread(void *arg) {
  Thread_Pool *poo = (Thread_Pool *)arg;
  poo->Work();
  return NULL;
}

void Thread_Pool::Create_Thread() {
  for (int i = 0; i < thread_num; i++) {
    pthread_create(&Thread_array[i], NULL, General_Thread, this);
  }
}

void Thread_Pool::Work() {
  while (true) {
    pthread_mutex_lock(&mutex);

    while (task_Num == 0 && status == true) {
      pthread_cond_wait(&cond, &mutex);
      // 这是条件休眠，进入到条件变量的休眠队列，进入条件变量的休眠队列是会自动释放锁，这与sleep是不相同的。
    } // 不能用if，要用while，以防虚假唤醒。

    if (status == false) {
      cout << "ThreadPool not run....." << endl;
      break;
    } // 处理线程池未启用的状态。

    Socket *tmp = dequeue[front].task;
    if (tmp == nullptr) {
      cout << "tmp is nullptr" << endl;
      break;
    }
    front = (front + 1) % dequeue_size;
    task_Num--;
    // cout<<"Thread id: "<<pthread_self()<<endl;
    pthread_mutex_unlock(&mutex);

    tmp->Do_client();
  }
  // 发生意外情况也要及时释放锁
  pthread_mutex_unlock(&mutex);
}

void Mysql_config::Init_Mysql_config(const char *Sql_config_path) {
  if (Sql_config_path == nullptr) {
    cout << "config_path is nullptr!" << endl;
    return;
  }

  FILE *fp = fopen(Sql_config_path, "r");
  if (fp == nullptr) {
    perror("fopen config file failed");
    cout << "fopen config file failed! errno=" << errno << endl;
    return;
  }

  char line[MAXLINE]{0};
  int num = 0;

  while (fgets(line, MAXLINE - 2, fp) != nullptr) {
    num++;
    if (line[0] == '#' || line[0] == '\n') {
      continue;
    }

    char *Before = strtok(line, "=");
    char *After = strtok(nullptr, "=");

    if (Before == nullptr || After == nullptr) {
      continue;
    }

    After[strlen(After) - 1] = '\0';

    if (strcmp("dp_ip", Before) == 0) {
      db_ip = After; // 禁止共享内存，line是一次性使用，After会被覆盖
    } else if (strcmp("dp_port", Before) == 0) {
      db_port = atoi(After);
    } else if (strcmp("dp_name", Before) == 0) {
      db_name = After;
    } else if (strcmp("dp_mysql_path", Before) == 0) {
      Sql_config_path = After;
    } else {
      cout << "unknown config item: " << Before << " at line " << num << endl;
    }
    memset(line, 0, sizeof(line));
  }
  fclose(fp);
  print_Mysql_config();
}

bool Mysql_Client::Db_Yd_Ticket(std::string usertel, std::string tk_id) {
  if (!connected) return false;
  string sql_max_count =
      string("select tk_max,count from ticket_table where Tk_id=") + tk_id;
  if (mysql_query(mysql_con, sql_max_count.c_str()) != 0) {
    cout << "[预约] 查询票信息失败: " << mysql_error(mysql_con)
         << " | SQL: " << sql_max_count << endl;
    return false;
  }

  MYSQL_RES *r = mysql_store_result(mysql_con);
  if (r == NULL) {
    cout << "[预约] 取结果集失败: " << mysql_error(mysql_con) << endl;
    return false;
  }

  int num = mysql_num_rows(r);
  if (num == 0) {
    cout << "[预约] 未找到 Tk_id=" << tk_id << " 的票记录" << endl;
    mysql_free_result(r);
    return false;
  }

  MYSQL_ROW row = mysql_fetch_row(r);
  int max = atoi(row[0]);
  int count = atoi(row[1]);
  mysql_free_result(r);

  if (count >= max) {
    cout << "[预约] 票数不足 max=" << max << " count=" << count << endl;
    return false;
  }

  count++;

  Mysql_Begin();
  // 一旦开启事物，这两条sql语句都成功执行的情况下，才会去进行提交事物的操作，
  //  否则一旦有其中一个未成功，就算其中一个成功的操作也会撤销，二者立刻回滚，所有改动立即撤销，
  string sql_setcount = string("update ticket_table set count=") +
                        to_string(count) + string(" where Tk_id=") + tk_id;
  if (mysql_query(mysql_con, sql_setcount.c_str()) != 0) {
    cout << "[预约] 更新票数失败: " << mysql_error(mysql_con)
         << " | SQL: " << sql_setcount << endl;
    Mysql_RollBack();
    return false;
  }

  string sql_yd = string("insert into yd_table values(0,'") + usertel +
                  string("','") + tk_id + string("',now())");
  if (mysql_query(mysql_con, sql_yd.c_str()) != 0) {
    cout << "[预约] 写入预约表失败: " << mysql_error(mysql_con)
         << " | SQL: " << sql_yd << endl;
    Mysql_RollBack();
    return false;
  }

  Mysql_Commit();
  cout << "[预约] 成功: user_tel=" << usertel << " Tk_id=" << tk_id
       << " 剩余=" << (max - count) << endl;
  return true;
}

void Tcp_Service::Init(const Service_Config *config) {
  if (config == nullptr) {
    cout << "config is nullptr!" << endl;
    return;
  }
  this->config = config;
  Status = true;

  pool = new Thread_Pool;

  Mysql_config file;
  file.Init_Mysql_config(Sql_Conf_path);

  lis_fd = socket(AF_INET, SOCK_STREAM, 0);
  if (lis_fd == START) {
    perror("socket failed");
    cout << "socket failed! errno=" << errno << endl;
    exit(1);
  }

  // listen socket 设为非阻塞,accept 队列空时返回 EAGAIN 而不是阻塞
  int flags = fcntl(lis_fd, F_GETFL, 0);
  fcntl(lis_fd, F_SETFL, flags | O_NONBLOCK);
  // 因为是lis_fd为空导致的阻塞，所以我们这个将模式设为非阻塞，在此之后，accept会直接返回EAGAIN或EWOULDBLOCK，而不是阻塞线程
  // 不会阻塞

  int opt = 1;
  setsockopt(lis_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

  struct sockaddr_in server_addr;
  memset(&server_addr, 0, sizeof(server_addr));
  server_addr.sin_family = AF_INET;
  server_addr.sin_addr.s_addr = inet_addr(config->IP.c_str());
  server_addr.sin_port = htons(config->Port);

  config->PrintConfig();

  if (bind(lis_fd, (struct sockaddr *)&server_addr, sizeof(server_addr)) < 0) {
    perror("bind failed");
    cout << "bind failed! errno=" << errno << endl;
    exit(1);
  }

  if (listen(lis_fd, config->Lismax) < 0) {
    perror("listen failed");
    cout << "listen init error! errno=" << errno << endl;
    exit(1);
  }

  int epfd =
      epoll_create1(EPOLL_CLOEXEC); // 防止fork版本公用一个文件描述符的情况
  if (-1 == epfd) {
    perror("epoll_create1 failed");
    cout << "create epoll error! errno=" << errno << endl;
    close(lis_fd);
    exit(1);
  }

  ep_fd = epfd;
  cout << "epoll success!" << endl;

  struct epoll_event ev_listen;
  ev_listen.events = EPOLLIN;
  ev_listen.data.fd = lis_fd;

  if (epoll_ctl(epfd, EPOLL_CTL_ADD, lis_fd, &ev_listen) == -1) {
    perror("epoll_ctl add listen fd failed");
    cout << "epoll_ctl add false! errno=" << errno << endl;
    close(lis_fd);
    exit(1);
  }

  cout << "Tcp service success!" << endl;
  cout << "------------------------------------------------------" << endl;

  while (Status) {

    int ready_count = epoll_wait(epfd, ready_events, MAXLINE, -1);
    //- 内核 :负责把发生事件的 fd 放入就绪双链表(这是中断/回调驱动的,随时发生)
    // epoll_wait :负责从就绪双链表取出事件,拷贝给用户态的 ready_events
    if (ready_count == -1) {
      perror("epoll_wait failed");
      cout << "epoll_wait error! errno=" << errno << endl;
      close(lis_fd);
      exit(1);
    }

    for (int i = 0; i < ready_count; i++) {
      int tmfd = ready_events[i].data.fd;
      if (tmfd == lis_fd) {
        auto csocket = new AccSocket(lis_fd, epfd);
        pool->add_Task(csocket);
      } else {
        auto csocket = ready_events[i].data.ptr;
        if (csocket == nullptr) {
          cout << "csocket is nullptr" << endl;
          continue;
        }
        pool->add_Task((Socket *)csocket);
      }
    }
  }
}
```

#### 关键方法详解

##### `Tcp_Service::Init` ([L815-L917](service.cpp#L815))
主控函数：建线程池 → 建 listen fd（设非阻塞 + SO_REUSEADDR）→ bind → listen → epoll_create1 → epoll_ctl ADD listen fd → `while(Status)` 循环 epoll_wait。

##### `Thread_Pool::Work` ([L338-L366](service.cpp#L338))
worker 线程主循环：`pthread_mutex_lock` → `while(task_Num==0) cond_wait` → 取出 `dequeue[front].task` → unlock → `tmp->Do_client()` 多态分发。

##### `RecvSocket::Do_client` ([L164-L260](service.cpp#L164))
- recv 数据 → JSON 解析 → 构造 `Mysql_Client sql(&file, fd)`
- 检查 `sql.IsConnected()`：
  - false（池满）→ 跳过 Db_* 调用，构造里已 `Send_full()` 发了 BUSSY
  - true → 按 `val["type"]` 走 6 个业务分支
- 结束后 `epoll_ctl MOD` 重新监听（EPOLLONESHOT）

##### `Mysql_Client::Connect_Mysql_Server` ([L474-L499](service.cpp#L474))
加锁遍历 C_P_array，找到 `status==true` 的 slot → `mysql_con = C_P_array[i].mysql_con` → `status=false` → `user++` → 返回 true。借不到返回 false。

##### `Mysql_Client::~Mysql_Client` ([L740-L749](service.cpp#L740))
加锁遍历 C_P_array，找到 `mysql_con` 相等的 slot → `status=true` → `user--` 归还。

##### `Connect_Pool::Run` ([L776-L798](service.cpp#L776))
循环 5 次：`mysql_init` → `mysql_real_connect` → 存进 `C_P_array[i].mysql_con` + `status=true`。

##### `Connect_Pool::Reset` ([L801-L809](service.cpp#L801))
循环 5 次：若 `mysql_con != nullptr` 则 `mysql_close`，然后置 nullptr + status=false。

#### 业务方法
- `Db_User_Register` ([L501](service.cpp#L501)) — 插入 user_info
- `Db_User_Login` ([L517](service.cpp#L517)) — select Name,Passwd 比对
- `Db_Show_Ticket` ([L552](service.cpp#L552)) — select * 拼成 JSON
- `Db_Yd_Ticket` ([L585](service.cpp#L585)) — 事务：查 max/count → 更新 count → 插 yd_table
- `Db_Show_My_Ticket` ([L647](service.cpp#L647)) — JOIN yd_table + ticket_table
- `Db_Cancel_Ticket` ([L684](service.cpp#L684)) — 事务：查 tk_id → 删 yd → count-1

#### 设计亮点
- `Mysql_Client::IsConnected()` 让 Do_client 可以无侵入处理"池满"
- `Send_full()` 直接发 BUSSY 给客户端 fd，避免在 Do_client 多发一次 false
- 事务在 `Db_Yd_Ticket` / `Db_Cancel_Ticket` 中正确 begin/commit/rollback
- listen fd 设非阻塞 + accept 返回 EAGAIN 时不报错静默退出（多 worker 竞争保护）

#### 不足
- `Mysql_Client::mysql_con` 之前是野指针（已加 `mysql_con = nullptr;` 初始化修好）
- `day-time` vs `day_time` 字段名不一致（已修）
- `Connect_Pool::Run` 失败时局部 mysql 指针丢失（OS 兜底）
- SQL 全字符串拼接，存在注入风险

客户端发送：

#### 6 个业务方法
| 方法 | type | 流程 |
|------|------|------|
| `User_Register` | 2 | 输入 tel/name/passwd → send → recv → BUSY?/ok? |
| `User_login` | 1 | 同上 |
| `Show_Ticket` | 3 | 不带参数 → recv 列表 → 表格打印 |
| `Yd_Ticket` | 4 | 先 Show_Ticket → 输入序号 → send → recv |
| `Show_My_Ticket` | 5 | 带 user_tel → recv → 表格 |
| `Qx_Ticket` | 6 | 先 Show_My_Ticket → 输入 yd_id → send → recv |

#### 菜单逻辑
```cpp
switch(tmp) {

  case Register: User_Register(); break;
  ...
  case Exit: Running = false; break;
}
```

#### 设计亮点
- 统一 BUSY 检查模板：6 个方法都先判断 `s == BUSY` 提示"服务器繁忙"，再判断 `s != k` 提示具体失败
- 业务方法可组合（Yd_Ticket 复用 Show_Ticket，Qx_Ticket 复用 Show_My_Ticket）

- `recv` 阻塞，无超时（服务端挂起客户端会一直等）
- `cin >> tmp` 没检查失败状态（输入非数字会陷入死循环）
- 表格用 `printf` 硬编码列宽，长名会错位
- 全局 enum `OP_TYPE` 与服务端重复定义（应放共享头）
